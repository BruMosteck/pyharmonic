# 🌟 PyHarmonic

O **PyHarmonic** é uma aplicação desktop desenvolvida em Python (Tkinter) para computação numérica e simbólica. Ele combina a agilidade de um terminal interativo (estilo GNU Octave/MATLAB) com ferramentas visuais avançadas inspiradas no GeoGebra.

## 🚀 Funcionalidades Principais
* **Terminal Interativo (REPL):** Execução de comandos Python em tempo real com memória compartilhada entre abas.
* **Computação Numérica:** Operações avançadas com matrizes e vetores utilizando `NumPy`.
* **Visualização Gráfica:** Plotagem instantânea de funções e gráficos cartesianos com `Matplotlib`.
* **Módulo "Free Geogebra" (CAS):** 
  * Calculadora Gráfica com análise automática de raízes e pontos críticos.
  * Álgebra Simbólica para resolução de equações, fatoração e expansão polinomial.
  * Cálculo Avançado com resolução instantânea de derivadas e integrais usando `SymPy`.
  * Geometria Plana 2D.

## 🛠️ Tecnologias Utilizadas
* Python 3
* Tkinter (Interface Gráfica)
* NumPy (Álgebra Linear)
* Matplotlib (Plotagem de Gráficos)
* SymPy (Álgebra Simbólica e Cálculo)
